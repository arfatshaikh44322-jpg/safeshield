SMART DEVICE HABITS

Build Safer Everyday Habits

Device security is most effective when protection becomes part of your everyday digital routine.

01 / UPDATE

Don't Ignore Security Updates

Updates can contain important security fixes. Enable automatic updates when appropriate and review pending updates regularly.

02 / VERIFY

Think Before Installing

Check where an application or file came from before opening or installing it. Be cautious with unexpected downloads.

03 / BACKUP

Keep Another Copy

Backups can help you recover important information if a device is lost, damaged or affected by a security incident.
