What Is 2FA?

Two-factor authentication requires two different types of evidence before access is granted. This can combine something you know with something you have.

KNOW + HAVE = STRONGER LOGIN
📱

Authenticator Apps

Authenticator applications can generate temporary verification codes that are used alongside your password during login.

TIME-BASED CODES
📩

Security Codes

Some services send a one-time code to a registered phone number or email address as an additional verification step.

ONE-TIME VERIFICATION
🗝️

Security Keys

Physical security keys can provide a strong additional authentication factor for services that support them.

PHYSICAL AUTHENTICATION
🚨

Protect Verification Codes

Never give verification codes to someone who contacts you unexpectedly. A code can be used to complete an authentication attempt.

NEVER SHARE CODES
💾

Save Recovery Options

When a service provides recovery codes, store them securely. They may help you regain access if your normal second factor becomes unavailable.

AUTHENTICATION METHODS

Know Your Verification Options

Different services support different authentication methods. Understanding them helps you choose an option that works for you.

📱

Authenticator App

Generates temporary codes on a trusted device. It can be useful when a service supports app-based verification.

APP CODE
🔑

Security Key

A physical security device can provide an additional authentication factor when supported by the account.

PHYSICAL KEY
📩

One-Time Code

Some services use one-time codes delivered through supported communication channels as a second verification step.

ONE-TIME CODE
💡

Remember: 2FA does not replace good passwords

Use strong, unique passwords together with two-factor authentication. Keep your verification methods and recovery information private as well.

SMART 2FA HABITS

Protect the Second Factor Too

Additional authentication is only useful when the authentication method itself is protected.

🛡️

Keep Devices Secure

Protect the phone or device used for authentication with a screen lock and appropriate security updates.

DEVICE SECURITY
🚫

Never Share Codes

Treat authentication codes like passwords. Do not give them to people who contact you unexpectedly.

KEEP PRIVATE
🔄

Review Security Settings

Periodically review the devices and authentication methods connected to your important accounts.
